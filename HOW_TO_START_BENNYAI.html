BennyAI v1.0
Local AI Coding Assistant — How to Start Guide

1 Requirements

  • ✓
    Python 3.10+ — already installed on this PC. Verify: python --version
  • ✓
    Ollama — download from ollama.com and install. This runs the AI model locally.
  • ✓
    DeepSeek Coder model — pull it once with: ollama pull deepseek-coder:6.7b
  • !
    GTX 1050 Ti (4GB VRAM) — the 6.7b model fits but leaves very little headroom. Keep other GPU apps closed.

2 First-Time Setup Do once

Open a terminal (PowerShell or CMD) and run these commands in order:

# 1. Pull the AI model (one-time download, ~4GB) ollama pull deepseek-coder:6.7b # 2. Python packages install automatically on first launch, # but you can pre-install them now: pip install requests pdfplumber beautifulsoup4
The app auto-installs requests, pdfplumber, and beautifulsoup4 if missing on first run — so this step is optional.

3 How to Launch

Every time you want to use BennyAI:

# Make sure Ollama is running (it may start automatically, # or open the Ollama tray app first) ollama serve # In a separate terminal, launch BennyAI: python "D:\Documents\CODE\documentation_bot\bennyai.py"

Or double-click the file D:\Documents\CODE\documentation_bot\bennyai.py if Python is your default handler for .py files.

Shortcut tip: Create a .bat file on your Desktop with this content so you can double-click to launch:

@echo off
start "" "D:\Documents\CODE\documentation_bot\bennyai.py"

7 Usage Tips

  • →
    Set the workspace folder before asking about a project. Paste the project path in the top bar — BennyAI will read files from it automatically.
  • →
    Ask it to read and explore — say "map out this project" and it will list directories and read key files on its own.
  • →
    Download docs to the library — turn Online on and say "download the Django documentation to the library" so it can teach you offline later.
  • →
    Benchmark first on a new PC — click Benchmark in the header and BennyAI will test your hardware and recommend the right model.
  • !
    If it hangs (0 tok/s for 30+ seconds) — close BennyAI, open Task Manager and end any ollama process, then restart.
  • !
    VRAM at 97% is normal while generating — that's the model running. It drops back to ~9% when idle.

9 Moving to a New PC

BennyAI has a built-in transfer tool. In BennyAI, go to Settings → Transfer and click Export. This creates a ZIP that includes:

  • The BennyAI app file
  • All chat history
  • Your downloaded library
  • The Ollama model blobs
  • An auto-setup script that installs everything on the new machine
On the new PC: install Python + Ollama, copy the ZIP over, extract it, and run setup.bat (Windows) or setup.sh (Mac/Linux). It configures everything automatically.
